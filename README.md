# DevDocs

DevDocs is an AI-first internal documentation platform designed to help teams create, organize, search, and interact with their technical documentation.

## Features

- 📚 Documentation management
- 🔎 Fast document search
- 🤖 AI Assistant
- 🧠 Context-aware AI responses
- 🔔 Notification preferences
- 👤 User profile management
- ⚙️ Application settings
- 🎨 Dark, Light and System themes

## Tech Stack

### Frontend
- React
- TypeScript
- Vite
- React Router
- React Icons
- CSS

### Backend
- Node.js
- Express
- TypeScript
- PostgreSQL
- Drizzle ORM
